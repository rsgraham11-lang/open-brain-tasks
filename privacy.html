Privacy Policy

Last updated: September 24, 2026

Open Brain Tasks is a personal utility used only by its owner.

What it accesses

With the owner's permission (Google scope https://www.googleapis.com/auth/tasks), it reads tasks in one Google Tasks list and deletes each one after copying it.

Where the data goes

Each task's text is copied into the owner's own private task database. It is processed by an AI language model only to pull out a title, tags, and a due date.

Sharing

Data is never sold or shared with anyone else, and it is not used for advertising.

Storage and deletion

The Google sign-in token is stored only on the owner's own computer. Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Use the developer email shown on the Google sign-in screen for this app.
